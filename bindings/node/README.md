# ops — Node.js wrapper (npm)

Thin Node.js binding over the Rust `ops` core, compiled to a native
`.node` addon with [napi-rs](https://napi.rs). No logic lives here —
everything delegates to `the `ops` crate`.

- Build tooling: `napi-cli` (`@napi-rs/cli`)
